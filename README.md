## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
```

## Проверка сборки и оформления

```text
go fmt ./...
go build ./...
```

## 2 задание. Перевод минут в часы

Прочитайте одно целое неотрицательное число минут и выведите полные часы и оставшиеся минуты.

**Запуск из корня проекта:**

```text
go run ./cmd/time-converter
```

**Результат всех семи наборов:**

| Ввод | Полных часов | Оставшихся минут |
|---:|---:|---|
| `0` | 0 | 0 |
| `59` | 0 | 59 |
| `60` | 1 | 0 |
| `125` | 2 | 5 |
| `1500` | 25 | 0 |
| `-1` | — | — |
| `abc` | — | — |

## Дополнительное задание. Среднее время решения

Даны три целых значения времени: `20`, `25` и `35` минут. Запишите их в переменные, найдите сумму и среднее арифметическое, выведите среднее с двумя знаками после точки.

**Результат:**

```text
Сумма элементов: 80
Среднее значение: 26.67
``` 

**Запуск из корня проекта:**

```text
go run ./cmd/average
```
